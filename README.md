# React Search Filter

A responsive React interface for searching and browsing a curated collection of words.

![React Search Filter screenshot](screenshot.png)

## Features

- Fast case-insensitive word filtering
- Copy a result by selecting its word chip
- Responsive fixed header with a mobile menu
- Result count, clear search, and empty states
- Icon-only portfolio, social, and support links in the footer
- Floating back-to-top control

## Tech stack

React, Create React App, CSS, and React Icons.

## Run locally

```bash
npm install
npm start
```

Create a production build with `npm run build`. Deploy to GitHub Pages with `npm run deploy`.
